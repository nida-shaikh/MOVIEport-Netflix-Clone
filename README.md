🎬 MOVIEport - Netflix Style Video Streaming App
A premium, high-performance Video Streaming UI built with React, Vite, and Tailwind CSS. Inspired by Netflix and MovieBox, specifically designed for K-Drama and Movie enthusiasts.

🚀 Live Demo
👉 Click here to visit the Live App

✨ Features
🔍 Debounced Search: Optimized API calls with 500ms delay to reduce server load.
🎬 Auto-Sliding Hero Carousel: Netflix-style banner that changes automatically.
❤️ Persistent Watchlist: Add to favorites using Context API & LocalStorage (Survives page refresh).
📱 Fully Responsive: Mobile Hamburger Menu & Desktop Sidebar layout (MovieBox style).
⚡ Performance Optimized: Lazy Loading (Code Splitting) & Skeleton Shimmers for better UX.
🔔 Custom Toast Notifications: Beautiful popups instead of boring alerts.
🎭 Movie Detail Page: With YouTube Trailer integration & "You Might Also Like" section.
📺 TV Shows Page: Separate page for TV series categories.
🔐 Login Modal: Premium Glassmorphism UI for authentication screen.
🛠️ Tech Stack
Frontend: React, Vite
Styling: Tailwind CSS, Glassmorphism UI
State Management: Context API
API: OMDb API
Routing: React Router DOM v6
Deployment: Vercel
🚀 How to Run Locally
If you want to run this project on your own machine:

Clone the repository:
git clone https://github.com/nida-shaikh/MOVIEport-Netflix-Clone.git
Go to the project folder:
bash

cd MOVIEport-Netflix-Clone
Install dependencies:
bash

npm install
Add your OMDb API key in src/utils/axios.js
Start the server:
bash

npm run dev
